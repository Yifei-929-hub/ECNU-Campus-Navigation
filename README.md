# 华东师范大学校园导航系统 ECNU Campus Navigation

数据结构课程设计项目。基于 C++ 实现的控制台校园导航程序：用**邻接矩阵**存储华东师范大学（中山北路校区）13 个地点和 19 条道路组成的带权无向图，支持查看地点信息，并使用 **Dijkstra 算法**查询任意两地点之间的最短路径。

## 功能

```
*****！欢迎来到华东师范大学校园地图查询系统！*****
************  请选择您想进行的操作：  ************
*******  1、查询华东师范大学所有地点信息  ********
****  2、查询华东师范大学任一地点的基本信息  *****
*******  3、查询两个地点间的最短路径和长度  ******
*****************  4、退出系统  ******************
```

1. **查询所有地点信息**：列出全部地点的名称、代号和简介
2. **查询某一地点信息**：输入地点名称，显示该地点的代号和简介
3. **查询最短路径**：输入两个地点名称（空格分隔），输出最短路径长度和途经地点
4. **退出系统**

运行示例：

```
请输入任意两地的名称（名称之间用空格隔开，以回车结束）：
东门 西南2门
从东门到西南2门的路径长度为:1050	路径为：东门->河东食堂->田家炳教育书院->北门->河西食堂->西南2门
```

## 实现要点

- **存储结构**：`Graph` 结构体包含顶点表 `vexs[]`（名称、代号、简介）和邻接矩阵 `arc[][]`，不相邻的两点之间权值为 `INF`（999999）
- **建图**：`createGraph()` 根据边的起点、终点名称定位顶点下标，对称写入邻接矩阵
- **最短路径**：`shortestPath()` 实现 Dijkstra 算法，`pre[]` 记录前驱，`Dispath()` 根据前驱数组回溯并输出完整路径

## 运行方式

### Visual Studio（推荐）

1. 用 Visual Studio 2022 打开 `CampusNavigation.sln`（需安装「使用 C++ 的桌面开发」工作负载）
2. 按 `Ctrl + F5` 运行

### g++ / MinGW

```bash
g++ -std=c++11 -fexec-charset=GBK -o campus CampusNavigation/main.cpp
./campus
```

> 源文件为 UTF-8 编码。在中文 Windows 控制台（GBK）中运行时，用 `-fexec-charset=GBK` 编译可避免中文乱码；如果终端是 UTF-8 的（Linux / macOS），去掉该参数即可。

## 使用提示

- 查询时需输入地点的**完整名称**，如 `田家炳教育书院`、`西南2门`
- 查询路径时两个地点名称之间用空格隔开
